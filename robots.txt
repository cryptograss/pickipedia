# PickiPedia — crawler directives
#
# Why this file exists: MediaWiki hands out an effectively unbounded URL space.
# Every revision of every page is fetchable, and so is the diff between any two
# of them. With ~4,000 edits across ~780 pages that is a combinatorial pile of
# URLs, none of which anyone wants to read, all of which a crawler will happily
# walk. Left unfenced, the crawl budget goes there instead of to the ~165
# actual articles, and the articles get visited rarely or not at all.
#
# Nothing here is about hiding content. Everything blocked below is either a
# duplicate of an article that is already indexable at /wiki/, or machinery.

User-agent: *

# The raw entry point. Every action=edit, action=history, diff= and oldid= URL
# hangs off it. Articles themselves are served from /wiki/ (see $wgArticlePath)
# and stay crawlable.
Disallow: /index.php

# Machine interfaces. No reader-facing content, and the query space is endless.
Disallow: /api.php
Disallow: /rest.php

# Special pages. Some are infinite generators on their own — Special:Random
# alone will keep a crawler busy forever — and several are expensive queries
# that make the database work hard for no indexable payoff.
Disallow: /wiki/Special:
Disallow: /wiki/Special%3A

# Deliberately NOT blocked: /load.php. It serves the CSS and JavaScript that
# search engines need in order to render pages the way a reader sees them.
# Blocking it makes a wiki look broken to the crawler.

# Bandwidth-hungry scrapers, already refused at the Apache layer in .htaccess.
# Repeating the refusal here turns them away before they cost us a request.
User-agent: meta-externalagent
Disallow: /

User-agent: Amazonbot
Disallow: /

# Generated by maintenance/generateSitemap.php, served from outside the
# MediaWiki tree so deploys don't sweep it away. See the pickipedia-vps role
# in cryptograss/maybelle-config for the timer that refreshes it.
Sitemap: https://pickipedia.xyz/sitemap/sitemap-index-pickipedia.xml
